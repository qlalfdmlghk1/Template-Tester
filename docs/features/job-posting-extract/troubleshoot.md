# job-posting-extract — 트러블슈팅

## 모달 윗부분이 잘려 보이던 문제 (2026-08-15)

### 증상

지원 건 추가 모달에 모집 요강 섹션이 붙어 세로로 길어지자 **모달 상단이 잘려 보였다.**
스크롤 문제로 보여 헤더·푸터 고정을 먼저 넣었지만 증상이 그대로였다.

### 원인

**네비게이션 바가 모달 위에 그려지고 있었다.**

| 요소 | z-index |
| --- | --- |
| Navbar (`sticky top-0`) | `z-[1000]` |
| 모달 6개 전부 | `z-50` |

모달은 `fixed inset-0` + `items-center` 라 세로 가운데 정렬된다. 짧을 때는 네비게이션
영역까지 올라오지 않아 문제가 드러나지 않았는데, 폼이 길어져 상단이 네비게이션 높이
안으로 들어가면서 그 부분이 가려졌다. **잘린 게 아니라 덮인 것**이다.

### 해결

한 곳만 숫자를 올리면 다음 오버레이에서 같은 사고가 반복되므로 겹침 순서를
`tailwind.config.js` 토큰으로 고정했다.

```js
zIndex: { dropdown: 100, navbar: 1000, modal: 1100, toast: 1200 }
```

- 모달 6개(`지원 건 추가·수정`, `붙여넣기`, `전형 단계 편집`, `XLSX 가져오기`, `AI 키`, `확인`) → `z-modal`
- Navbar `z-[1000]` → `z-navbar`
- 토스트 `z-50` → `z-toast` — 모달을 1100으로 올리면서 **모달 위 토스트가 가려지게 되어** 함께 올렸다

### 배운 것

- "잘린다"는 증상은 스크롤·오버플로 문제로 읽히기 쉽지만 **z-index로 덮인 경우도 같은 모습**이다.
  스크롤 컨테이너를 손봐도 증상이 남으면 겹침 순서를 먼저 의심한다.
- 오버레이 z-index를 컴포넌트마다 임의 값으로 두면 서로의 존재를 모른 채 어긋난다.
  값이 흩어지기 전에 토큰으로 모아야 한다.
