## 🎯 작업 목적

## 📋 작업 범위

**포함 (In Scope)**

지원 현황 페이지

- [ ] 페이지 제목이 '채용'으로 표시되는 문제 → '지원 현황'으로 수정
- [ ] 기업명 검색으로도 목록 조회 가능하도록 검색 대상 확장
- [ ] 행 클릭 시 우측 상세 내역에서 "모집 요강" 제외 (상태 · 채용 인원 · 공고링크 · 전형 진행만 노출)
- [ ] 상세 내역의 "기업 조사" 버튼 옆에 `>` 아이콘 추가 (텍스트가 아닌 아이콘으로)
- [ ] 지원 건 추가 모달에서 "공고명" 미입력 시 해당 반기 값으로 자동 입력 (예: `2026 하반기`)

기업 조사 페이지

- [ ] "조사 완료" 토글 네이밍 → "조사 된 기업"으로 변경
- [ ] 필터에서 공기업 · 대기업 · 금융권 그룹과 A · B · C · D 그룹이 시각적으로 구분되게 배치

## ✅ 검증 계획

- 단위/통합 테스트: 공고명 기본값 생성(반기 판정) 로직 — 순수 함수로 분리 시 Vitest 대상. 검색 필터 훅 변경분 확인
- 회귀 포인트:
  - 반기 판정 로직은 최근 변경 이력이 있으므로(#85) 기존 동작과 충돌 여부 확인
  - 상세 패널에서 "모집 요강" 제거가 다른 화면(기업 조사 상세 등)에 영향 없는지 확인
  - 검색 대상 확장이 기존 검색 결과(공고명 검색)를 깨뜨리지 않는지 확인
- 수동 확인:
  - 지원 현황: 제목 문구, 기업명 검색, 행 클릭 → 상세 항목 4종만 노출, "기업 조사 >" 아이콘, 공고명 빈 값으로 저장 시 자동 입력
  - 기업 조사: 토글 문구, 필터 두 그룹의 시각적 구분
