## 🤔 주요 결정 사항

- **[2026-08-03] 반기 필터 '전체'** — 라벨만 바꾸지 않고 **동작을 바꾸기로** 결정. `미분류`를 선택지에서 빼고 `ALL_HALF_ID`(`"all"`) 선택지를 맨 앞에 추가해, 반기 무관 전체 지원 건(자소서 일정 없는 건 포함)을 보여준다. `UNASSIGNED_HALF_ID`는 내부 그룹 값으로는 남아 있고 선택지로만 노출하지 않는다.
  - 기본 선택은 종전대로 "현재 반기 → 최신 반기" 순이며, `전체`는 실제 반기가 하나도 없을 때만 폴백으로 잡힌다.
- **[2026-08-03] 서비스명 수정 — 보류** (이번 PR 제외). 후보로 `All About Developers`(축약 `AAD`)까지 논의했으나 사용자가 재검토하기로 해 코드 변경은 되돌렸다. 재개 시 참고:
  - 바꿀 사용자 노출 지점 4곳 — `index.html`의 `<title>`, `Navbar.tsx`의 로고 `alt`·서비스명 텍스트(모바일 2줄 분리 포함), `Login.tsx` 안내 문구, `Signup.tsx` 안내 문구.
  - **바꾸면 안 되는 곳** — Firebase 프로젝트 ID(`template-tester-1540c`), 로그인 이메일 도메인(`@template-tester.local`), IndexedDB 이름(`template-tester-daily`), sessionStorage 키(`template-tester:solve-logs`). 기존 사용자 계정·캐시가 끊긴다.
  - `AAD`는 Azure Active Directory 약어와 겹쳐 개발자 타깃에서 혼동 여지가 있다.
