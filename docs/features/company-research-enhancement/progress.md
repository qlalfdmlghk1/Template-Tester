- [2026-08-08] /start 실행, 작업 환경 셋업 완료
- [2026-08-08] **AI 호출 경로 = 사용자 본인 키 + 클라이언트 직접 호출** (두 번 뒤집힌 결정)
  - 처음엔 Functions 프록시 재사용으로 정했으나, Functions 배포에 Blaze(카드 등록)가 필수라는 제약 때문에 뒤집음
  - 대안 3가지(무료 프록시 이전 / 사용자 본인 키 / AI 조사 보류) 중, **사용 범위가 본인 + 지인 소수**여서 사용자 본인 키를 선택
  - 근거: 우리 키가 아니라 사용자 키라 유출 시 피해가 본인 크레딧으로 한정. 레포에 `dangerouslySetInnerHTML` 0건, 런타임 의존성 11개로 XSS·공급망 표면이 작음
  - 남는 위험은 공급망(FE 의존성 오염 시 키 탈취) → **FE에 Anthropic SDK를 추가하지 않고 `fetch`로 호출**해 표면을 더 줄임
  - 재검토 조건: 불특정 다수가 쓰는 서비스가 되면 무료 프록시(Cloudflare Workers 등)로 전환
- [2026-08-08] **Daily 학습도 사용자 키 방식으로 이전 결정** → 후속 이슈 [#82](https://github.com/qlalfdmlghk1/Template-Tester/issues/82). `functions/` 제거까지 포함하며, 완료되면 프로젝트에서 Blaze(카드) 요구가 완전히 사라지고 Windows 에뮬레이터 기동 문제도 해소됨. **#81의 CORS 검증 통과 후 착수** (막힐 경우 대비해 Functions를 먼저 지우지 않음)
- [2026-08-08] **공고 마감일 기능 폐기**. 마감일의 소속 엔티티(`Company` vs `JobApplication`)가 미결 — `Company`는 재지원해도 1건만 유지되는데 마감일은 공고마다 다름. 잘못 정하면 되돌리는 비용이 커서 별도 이슈로 분리
- [2026-08-08] **AI 조사 = 웹 검색 근거**. "최근 이슈"는 모델 파라메트릭 지식만으로는 원리적으로 채울 수 없어(학습 컷오프) 서버사이드 웹 검색 도구를 사용하기로 함. 각 항목에 출처 URL을 함께 저장
- [2026-08-08] **자소서 문항 메모는 기획서 3.4 "자기소개서 관리"로 이관**. 중복 기획이라 이번 범위에서 제외. 3.4가 미구현이라 지금은 연결할 대상이 없어 연결 지점만 열어둠
