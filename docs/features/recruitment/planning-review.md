## ✅ 해소된 항목 (🚫 5건)

#### 1. 레코드 단위가 "기업"인지 "지원 건"인지 불명확

- **근거**: 스크린샷 10행·16행에 현대오토에버가 중복 등장(자소서 03/23, 07/13). plan.md는 기업 단위로 서술.
- **결정**: `companies` / `applications` **두 컬렉션으로 분리**. 그리드는 `applications` 기준 렌더. 조사 노트가 기업 단위라 합치면 중복 보관되는 점이 결정 근거.

#### 2. "반기" 정의와 귀속 기준 미정 — 스크린샷과 어긋남

- **근거**: `상반기_2026` 시트에 07/13·08/09 일정 포함.
- **결정**: 경계는 **1~6월 / 7~12월**, 귀속은 **자소서 마감일 기준 자동**. 스크린샷의 07·08월 건은 정리 누락이었음이 사용자 확인으로 밝혀짐.

#### 3. CSV 임포트에 상태 정보가 존재하지 않음

- **근거**: 상태가 전부 셀 배경색. CSV 내보내기 시 서식·메모·하이퍼링크 전부 소실.
- **결정**: **xlsx 업로드로 변경.** 셀 배경색 hex → 상태 매핑으로 파싱. CSV 임포트는 Out of Scope로 이동.

#### 4. 러프 일정 표기의 저장·비교 규칙 미정

- **근거**: `4월 중`·`5월 초`·`7월 중순 ~ 말` 등 비정형 표기 혼재.
- **결정**: **선택지로 구조화** (월 + 초/중순/말). `4월 중 (1박 2일)` 같은 부가 정보는 셀 메모로 흡수. 기존 자유 텍스트 → 선택지 매핑 파싱이 임포트에 필요.

#### 5. 합격률 계산식·집계 대상·경계 처리 미확정

- **근거**: plan.md에 역산 추정치로만 기록돼 있었음.
- **결정**: `PASSED / (PASSED + FAILED)` 확정 (`SUBMITTED`·`PENDING`·`NOT_APPLICABLE` 분모 제외). 집계 대상은 **전형 8단계**(자소서~2차 면접) — 최종발표·출근 제외.
- **잔여**: 분모 0일 때 표시 방식 미확정 → 아래 ⚠️로 이월.

## ✅ 해소된 항목 (⚠️ 4건)

| 항목                  | 결정                                                                    |
| --------------------- | ----------------------------------------------------------------------- |
| 지원 건 전체 상태     | 단계 상태에서 **자동 파생** (탈락/최종 합격/미지원/진행 중), 별도 입력 X |
| 기업 조사 노트 위치   | **별도 탭/페이지** — 지원하지 않은 기업도 목록 유지                     |
| 인증·데이터 소유      | **로그인 필수**, 사용자별 개인 데이터, Firestore 규칙에 `ownerId` 반영  |
| 임포트 병합 정책      | **미리보기 후 사용자가 행 단위 선택** — 덮어쓰기 사고 방지              |
| 정렬·필터             | **마감일순 정렬 기본 + 직무·상태 필터**                                 |

## ✅ 해소된 항목 (⚠️ 4건 · 💡 5건 — 2차 답변)

| 항목                     | 결정                                                                          |
| ------------------------ | ----------------------------------------------------------------------------- |
| 합격률 분모 0            | `-` 표시 — "진행 전"과 "전원 탈락"을 구분하기 위해                            |
| 미지원 건 처리           | 목록 유지 + 합격률 집계 제외, 행은 흐리게                                     |
| 셀 편집 저장             | 즉시 저장 (낙관적 업데이트 + 실패 시 롤백)                                    |
| 저장·삭제 피드백         | 토스트 + 삭제 확인 다이얼로그                                                 |
| 빈·로딩·에러             | 세 가지 모두 — 빈 상태에 xlsx 임포트 유도 / 스켈레톤 / 재시도 버튼            |
| 상태 구분 (접근성)       | 아이콘 + 색상 병기                                                            |
| 메모 단위                | 지원 건 + 단계 셀 **둘 다** (기존 시트와 동일)                                |
| 직무 태그                | 고정 세트 (IT·SW·FE·PM), 색상 매핑 유지                                       |
| 채용 인원 `00명`         | **공고 원문 표기**였음 → 미정(`null`) 허용, 화면은 "미정", 임포트 시 매핑     |
| 지난 반기 데이터         | 편집 가능. 반기는 자동 귀속이라 "새 반기 생성" 동작 자체가 불필요             |
