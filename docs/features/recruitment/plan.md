## 🎯 작업 목적

사용자가 채용 공고를 한곳에서 확인하고 지원 현황을 관리할 수 있게, 그리고 채용기간이 아닌 경우에는 다음 반기에 지원할 기업에 대해 미리 조사함으로써 미리 대비하기 위함

## 🛠️ 접근 방식

### 확정 사항 (2026-08-02 기획 검수 결과 반영)

**데이터 모델 — 기업과 지원 건 분리**

```
companies      기업명, 공고 링크, 위치, 조사 노트, ownerId
applications   companyId(참조), 공고명, 반기, 직무 태그, 채용 인원,
               전형 10단계 상태·일정, 미지원 사유, ownerId
```

- 같은 기업 재지원 시 지원 건만 추가. 그리드는 `applications` 기준으로 렌더하므로 화면은 기존 시트와 동일하게 보임.
- 같은 반기 내 동일 기업 복수 건은 **공고명**으로 구분.
- 조사 노트는 `companies`에 두어 지원 건마다 중복되지 않게 함.

**전형 단계 — 고정 10단계**

자소서 → AI 역량검사 → 인성검사 → 직무/적성 → 필기 → 코딩 테스트 → 1차 면접 → 2차 면접 → 최종발표 → 출근

**단계 상태 5종** (기존 구글 시트 셀 배경색 체계에서 도출)

| 상태             | 시트 색상 | 의미                  |
| ---------------- | --------- | --------------------- |
| `PASSED`         | 초록      | 해당 단계 합격(통과)  |
| `SUBMITTED`      | 파랑      | 응시·제출, 결과 미정  |
| `FAILED`         | 빨강      | 해당 단계 불합격      |
| `NOT_APPLICABLE` | 회색      | 해당 기업에 없는 단계 |
| `PENDING`        | 무색      | 아직 진행 전 (기본값) |

**지원 건 전체 상태 — 단계 상태에서 자동 파생**

- 어느 단계든 `FAILED` → 탈락
- 출근 단계 `PASSED` → 최종 합격
- 미지원 사유가 입력됨 → 미지원
- 그 외 → 진행 중

**합격률**

- 계산식: `PASSED / (PASSED + FAILED)` — `SUBMITTED`·`PENDING`·`NOT_APPLICABLE`은 분모 제외
- 집계 대상: **전형 8단계**(자소서 ~ 2차 면접). 최종발표·출근은 결과·후속 단계라 제외
- 분모 0일 때 표시 방식은 미확정 — 구현 시 확인 (`-` 권장, 확정 아님)

**반기**

- 경계: 1~6월 = 상반기 / 7~12월 = 하반기
- 귀속: **자소서 마감일 기준 자동**

**일정 표기**

- 정확한 일시 / 기간 / 러프 선택지(월 + 초·중순·말)로 **구조화**
- 러프 표기는 정렬·"가장 임박한 일정" 계산 시 대표 시점으로 환산 (환산 규칙은 구현 시 확정)
- `4월 중 (1박 2일)`·`04/04 (토)` 같은 부가 정보는 선택지에 담기지 않으므로 **셀 메모로 흡수**

**xlsx 임포트**

- CSV는 셀 배경색·메모·하이퍼링크가 전부 소실돼 상태를 가져올 수 없으므로 xlsx 파싱으로 확정
- 셀 배경색 hex → 단계 상태 매핑. 실제 파일에서 색상값 분포를 먼저 확인해야 함 (수동 색칠이면 미묘한 색 차이가 섞였을 수 있음)
- 기존 자유 텍스트 일정("4월 중")을 구조화 선택지로 매핑하는 파싱 필요
- 반영 방식: 파싱 결과 **미리보기 후 사용자가 행 단위로 선택**

**인증**

- Firebase Auth 로그인 필수, 사용자별 개인 데이터. Firestore 보안 규칙에 `ownerId` 기반 소유권 반영

**UI·인터랙션** (2026-08-02 확정 — 기획 검수 ⚠️/💡 잔여분)

- 합격률 분모 0일 때는 `-` 표시. `0.00%`로 두면 "아직 진행 전"과 "전원 탈락"이 구분되지 않음
- 미지원 사유가 입력된 지원 건은 **목록에 유지하되 합격률 집계에서 제외**. 행은 흐리게 처리
- 그리드 셀 편집은 **즉시 저장** — 낙관적 업데이트 후 실패 시 롤백
- 저장·삭제 성공/실패는 **토스트**로 알림. 삭제는 **확인 다이얼로그** 경유
- 빈 상태·로딩·에러 세 가지 모두 구현
  - 빈 상태: 안내 문구 + xlsx 임포트 유도 (첫 진입 동선)
  - 로딩: 스켈레톤
  - 에러: 재시도 버튼
- 단계 상태는 **아이콘 + 색상** 병기 — 색상 단독은 색각 이상 사용자가 구분 불가
- 메모는 **지원 건 단위 + 단계 셀 단위 둘 다** (기존 시트와 동일)
- 직무 태그는 **고정 세트**(IT·SW·FE·PM), 색상 매핑 유지
- 채용 인원은 **미정 허용**. 공고에 `00명`으로 표기된 경우가 있어 숫자 강제 불가 — 저장은 `null`, 화면은 "미정". xlsx 임포트 시 `00명` → `null` 매핑
- 지난 반기 데이터도 **편집 가능** (개인 기록이라 누락·오기 보정 필요)
- **반기는 별도 생성 동작이 없음** — 자소서 마감일로 자동 귀속되므로, 지원 건이 추가되면 해당 반기가 선택지에 자연히 생김
