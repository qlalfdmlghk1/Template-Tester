### 📌 구현 중 확인된 사실

- 라우팅은 `vite-plugin-pages` 기반 파일 라우팅이다. `app/router/` 디렉터리는 없다.
- `/companies` 페이지가 "기업 조사" 플레이스홀더로 이미 존재했고, 이를 채우는 방향으로 진행했다.
- **TanStack Query·Zustand는 미설치**다. `fe-convention.md`는 둘을 전제하지만 실제 코드는 커스텀 훅 + Firestore 직접 호출 패턴이며, 이번 작업도 기존 패턴을 따랐다.
- 색상 토큰은 CSS 변수 기반이라 다크 테마에서 변수 값이 바뀐다. `dark:` 접두사를 쓰면 안 된다.
- `AppIcon`은 iconify heroicons 이름을 받는다 (lucide 아님).

### 📊 실제 시트 분석 결과 (2026-08-02)

사용자 제공 `sheet1.xlsx` 를 분석해 확정한 사항.

- **시트 4개**: 상반기 / 하반기 / 2026_상반기 / 채용 정보. 앞 3개가 임포트 대상이고, "채용 정보"(직무 설명·자격 요건)는 조사 노트용이라 제외한다 — 전형 컬럼이 없으므로 파서가 자동으로 건너뛴다.
- **시트마다 컬럼 순서가 다르다.** 상반기는 `직무, 기업명, 자소서…`, 2026_상반기는 `기업명, 직무, 인원, 자소서…`, 하반기에는 `분류` 컬럼이 더 있다. 고정 인덱스를 쓸 수 없어 헤더 텍스트로 매핑한다.
- **셀 배경색 → 상태** (조건부 서식 아님, 고정 색상 11종)

  | 색상 | 의미 |
  | --- | --- |
  | `D9EAD3` | 합격 |
  | `C9DAF8` | 응시·제출 |
  | `F4CCCC` | 불합격 |
  | `F9CB9C` · `FCE5CD` | 불참·포기 (`SKIPPED` — 이번에 도메인에 추가) |
  | `F3F3F3` | 해당 없음 |
  | `D9D9D9` | **상태 아님** — 기업명 열 스타일로만 쓰임 (상반기 39개·하반기 20개 전부 B열) |
  | `FFFFFF` · 없음 | 진행 전 |

- **기업명 셀에 공고 하이퍼링크가 걸려 있다.** 이걸 `Company.postingUrl` 로 옮긴다.
- 일정은 Excel serial number(날짜 셀)와 문자열이 섞여 있다. 문자열은 `04/03 ~ 04/11`, `04/11 13:40-16시`, `4월 중`, `8월초`, `7월 중순 ~ 말` 등 형태가 다양해, 파싱 결과가 원문을 온전히 담지 못하면 원문을 셀 메모로 보존한다.
- 문자열 일정에는 연도가 없어 같은 행의 날짜 셀 → 시트 최빈 연도 순으로 기준 연도를 정한다.
- **SheetJS 커뮤니티 버전은 셀 배경색을 읽지 못한다**(스타일은 Pro 전용). 상태가 색으로만 표현된 이 시트에는 쓸 수 없어 `exceljs` 로 변경했다. 번들이 커서 동적 import 로 분리했다 (별도 청크 937KB, 임포트 다이얼로그를 열 때만 로드).

**트러블슈팅**

- 임포트한 기업명이 `[object Object]` 로 저장됨. 하이퍼링크 셀은 `{ text, hyperlink }` 인데 그 `text` 가 다시 `{ richText: [...] }` 객체인 경우가 2건(신한은행·한국투자증권) 있었고, 한 겹만 벗기고 `String()` 을 씌워 발생했다. 안쪽 값을 같은 규칙으로 재귀 처리하도록 고치고 회귀 테스트를 남겼다. 같은 원인으로 링크가 걸린 날짜 셀 1건도 일정으로 읽지 못하던 것을 함께 고쳤다.
